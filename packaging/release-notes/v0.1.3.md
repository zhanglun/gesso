# Gesso 0.1.3

> 修复版本：Windows 视频呈现与桌面壳层稳定性、应用内更新检查和窗口激活行为。

Gesso 0.1.3 收敛了 0.1.2 发布后的关键修复，并统一了更新检查、失败反馈和 macOS 菜单栏应用行为。

## 主要变化

- 修复部分 Windows 机器上的视频壁纸黑屏：补齐全屏 quad 呈现所需的图元拓扑、顶点缓冲、填充常量绑定和裁剪配置。
- 复用已有的 Windows 壁纸 WorkerW，只在没有可用宿主时创建，避免反复启动退出累积孤儿 WorkerW。
- Windows 退出和崩溃清理后重新设置用户原有桌面壁纸，修复部分驱动与 DWM 组合下的残留黑屏或最后一帧。
- 更新检查改为只读取 GitHub Release 的静态 `latest.json` 清单，不再访问未认证 GitHub REST API。
- 更新失败界面提供明确的失败原因、发布页入口和低干扰的错误详情复制操作；修复失败后重试状态无法恢复的问题。
- macOS 管理窗口和更新窗口创建后主动激活；应用以菜单栏常驻方式运行，不进入 Cmd+Tab 应用切换列表。
- 保留填充模式、随机换壁纸、恢复后随机指派和显示器详情等 0.1.2 已交付能力。

## 已知限制

- Windows 多显示器真实硬件回归仍在路线图中；Windows 单显示器使用已完成真机验证。
- 产物不签名、不公证。macOS 首次打开请在访达中右键应用并选择“打开”；Windows 可使用安装包或便携包。
