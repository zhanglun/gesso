# Gesso 0.1.3

> 修复版本：Windows 视频呈现、桌面壳层稳定性和应用内更新体验。
>
> Fix release: Windows video rendering, desktop shell stability, and in-app updates.

## 主要变化 · Highlights

- 修复部分 Windows 机器上的视频壁纸黑屏。
  Fixed black video wallpapers on some Windows systems.
- 改进 WorkerW 复用和退出清理，减少桌面残留问题。
  Improved WorkerW reuse and desktop cleanup on exit.
- 更新检查改用静态 `latest.json`，并改善失败重试和错误反馈。
  Update checks now use a static `latest.json` manifest, with improved retry and error feedback.
- 修复 macOS 管理窗口和更新窗口的激活行为。
  Fixed manager and update window activation on macOS.

产物未签名或公证。macOS 首次打开请在访达中右键应用并选择“打开”；Windows 如遇 SmartScreen，请选择“更多信息 → 仍要运行”。

Builds are unsigned and not notarized. On macOS, right-click the app in Finder and choose **Open**. On Windows, choose **More info → Run anyway** if SmartScreen appears.

## 已知限制 · Known limitations

- Windows 多显示器硬件回归仍在进行；Windows 单显示器已完成真机验证。
  Windows multi-monitor hardware verification is ongoing; single-display use is verified.
- Wallpaper Engine `scene` / `application` 项目暂不支持。
  Wallpaper Engine `scene` / `application` projects are not supported yet.
