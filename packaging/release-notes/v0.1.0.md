# Gesso 0.1.0

> 首次公开发布。Gesso 把视频、照片、Shader 和网页钉在桌面图标层之下，
> 跨平台、开源（MIT OR Apache-2.0）。
>
> 0.1 is the first public release — please open an issue if anything breaks.

## ✨ Highlights

- **Four wallpaper types**: video, photo, GLSL shader (Shadertoy subset), and HTML.
- **Below the desktop icons** on both platforms — wallpaper never steals your clicks.
- **Wallpaper Engine import** (`video` / `web` kinds): just point Gesso at a
  `project.json`. Zero-copy, read-only; it never scans your disk or requires Steam.
- **Multi-monitor**, per-display assignment and FPS.
- **System-aware**: auto-pause / downscale on fullscreen, idle, or battery.
- English & 简体中文 UI.

## 🔓 First launch (builds are unsigned)

Gesso is an open-source project with no code-signing credentials, so both
artifacts are unsigned. Nothing malicious here — you can build everything from
source. First-launch workarounds:

**macOS**
1. Open the `.dmg`, drag Gesso into Applications.
2. In Finder, **right-click → Open** (double-click is blocked for unsigned apps),
   then confirm Open.
3. If still blocked, run once in Terminal:
   `xattr -dr com.apple.quarantine /Applications/Gesso.app`

**Windows**
1. Unzip and run `gesso.exe`.
2. SmartScreen may appear → **More info → Run anyway**.
3. Requires the WebView2 Evergreen Runtime (preinstalled on most Windows 10/11;
   otherwise get it from Microsoft).

## ⚠️ Known limitations

- Windows multi-monitor pinning is implemented but only re-verified on a
  single-display setup so far.
- Wallpaper Engine `video`/`web` are supported; `scene`/`application` are not.
- Web wallpapers stay self-contained and offline: external iframes, top
  navigation, popups and forms are intentionally blocked.
