# Gesso 0.1.1

> 修复版本：Windows 安装包启动闪退、双平台视频卡顿、循环视频持续读盘，
> 以及一批发布后反馈的问题。

0.1.1 is a fix-first release, driven entirely by feedback after 0.1.0.

## ✨ Highlights

- **The Windows launcher works again (#2).** The 0.1.0 installer failed to
  start on every Windows machine — a black window that flashed and vanished.
  If 0.1.0 never opened for you, this is the release to try.
- **Smooth video wallpapers on both platforms.** Video no longer plays inside
  the embedded browser view; macOS (AVPlayerLayer) and Windows (Media
  Foundation + DXGI) now drive native players pinned under the desktop icons.
  4K60 clips and multi-monitor setups included.
- **Quiet disks.** Looping videos up to 256 MB are cached in memory, so loops
  and seeks no longer re-read the file from disk every round.
- **Web wallpapers are actually muted now** — the mute setting previously
  only applied to videos.
- Locking the screen pauses all wallpapers; waking from sleep no longer
  loses secondary displays or leaves ghost windows behind.
- Quitting — or even a crash — restores your original desktop instead of
  leaving a black screen.
- 10 built-in wallpapers (4 new shaders: Tide, Starfield, Silk, Ember), and
  sharper shader rendering on scaled displays (125%+ DPI).

## 🔓 First launch (builds are unsigned)

Same procedure as 0.1.0: macOS — right-click → Open in Finder; Windows —
SmartScreen → **More info → Run anyway**. Step-by-step instructions are in
the [0.1.0 release notes](https://github.com/zhanglun/gesso/releases/tag/v0.1.0).

Windows needs the WebView2 Evergreen Runtime (preinstalled on most
Windows 10/11; it powers shader, photo and web wallpapers).

## ⚠️ Known limitations

- Windows multi-monitor pinning is implemented; hardware verification so far
  covers single-display setups.
- Wallpaper Engine `video` / `web` projects are supported; `scene` and
  `application` are not (yet).
- Web wallpapers stay self-contained and offline: external iframes, top
  navigation, popups and forms are intentionally blocked.
