# Gesso 0.1.4

> 功能版本：新增锁屏快照同步（Windows + macOS），并修复副屏指派、更新代理、缩略图黑帧等问题。
>
> Feature release: lock screen snapshot sync (Windows + macOS), plus fixes for secondary display assignment, update proxies, and black thumbnails.

## 安装说明 · Installation

产物未签名（不公证）。首次打开方式：
- **macOS**：下载 DMG 拖入「应用程序」后，**右键点按 Gesso → 打开 → 打开**（直接双击会被 Gatekeeper 拦下）。
- **Windows**：SmartScreen 提示时点「更多信息 → 仍要运行」。

Unsigned builds (not notarized). First launch:
- **macOS**: drag Gesso into Applications, then right-click Gesso → Open → Open (double-click alone is blocked by Gatekeeper).
- **Windows**: on the SmartScreen prompt, choose "More info" → "Run anyway".

## 主要变化 · Highlights

- **新增 锁屏快照同步**（设置页「联动（实验）」，默认关）：锁屏显示当前壁纸的封面帧，关闭开关、恢复系统壁纸、移除条目或退出时自动恢复原锁屏设置。
  **New: Lock screen snapshot sync** (Settings → Experiments, off by default): the lock screen shows a cover frame of your current wallpaper; turning it off, restoring system wallpaper, removing the entry, or quitting restores your previous lock screen.
- Windows 走官方 `LockScreen` API；macOS 无公开锁屏 API，改为经官方桌面壁纸接口写入被壁纸窗盖住的桌面层，并支持多桌面跟随与逐桌面还原。
  On Windows it uses the official `LockScreen` API; on macOS (no public lock-screen API) it writes the cover frame to the desktop wallpaper layer behind Gesso's pinned window, with multi-Space follow and per-Space restore.
- 修复副屏无法指派壁纸：新增「为选屏挑壁纸」流程，双击卡片即指派到目标屏。
  Fixed wallpaper assignment to secondary displays: a new "pick wallpaper for this display" flow assigns on double-click.
- 修复 Windows 系统代理下更新检查失败（0.1.2 起的问题）。
  Fixed update checks failing behind system proxies on Windows (an issue since 0.1.2).
- 修复部分视频缩略图全黑并永久固化的问题。
  Fixed all-black thumbnails for some videos.
- 一轮界面走查：库列表插入时间倒序、显示器页反馈与设置页视觉修正等多处优化。
  UI polish round: library sorting, display-page feedback, settings-page visual fixes and more.

## 已知限制 · Known limitations

- 锁屏快照同步为实验特性，默认关闭；视频壁纸在锁屏上显示静态封面帧（动态视频上锁屏的扩展方案已因签名要求搁置，见技术方案 §10）。
  Lock screen snapshot sync is experimental and off by default; video wallpapers show a static cover frame on the lock screen (the dynamic-lock-screen extension route is shelved due to signing requirements, see tech notes §10).
- Windows 多显示器硬件回归仍在进行；Windows 单显示器已完成真机验证。
  Windows multi-monitor hardware verification is ongoing; single-display use is verified.
- Wallpaper Engine `scene` / `application` 项目暂不支持。
  Wallpaper Engine `scene` / `application` projects are not supported yet.
