小蜡烛 · 视觉概念稿 v0.2

方向选型用，非定稿。四版共用同一组约束：奶油蜡身 + 暖橙火苗 + 点状眼；每版给「清醒 / 睡眠」两态，浅色与深色壁纸底各一张（对应规格里的双底验证要求）。

A · 扁平极简

纯色蜡身、两层火苗、最少的细节。最接近 Gesso 管理窗口的克制气质，任何壁纸上都不抢戏；代价是个性最弱，奶感靠颜色不靠质感。

蜡身 FCF3E2 火苗 FFB65C 眼 4A3F35

B · 软胶柔光

蜡身带纵向柔光渐变、底部软阴影、一滴蜡泪和淡腮红——奶感最浓、生命感最强的一版；火苗三层色。风格化程度中等，与「安静观察者」气质最贴。

蜡身亮 FFFAF0 蜡身暗 F5E1C2 火苗 FFB65C 腮红 F5B98E

C · 手绘暖线

暖褐描边 + 蜡纹纸感底色，像画在便利贴上的小蜡烛；亲和力和涂鸦感最强，但描边在深色壁纸上会偏「卡通」，与极简工具气质略有张力。

蜡身 FBF1DD 描边 C4A87E 火苗 FFDCA0

D · 像素点阵

8px 点阵、直角硬边、抖动光晕——桌宠老祖宗（Tamagotchi / Neko）的血统；点眼是像素的天然语言，火苗摇曳只需 2~3 帧换帧，未来动作帧表和资源契约都最简单。深底上点阵光晕反而更出效果。

蜡身 FCF3E2 蜡身暗 F0DDB9 火苗 FFA94F 火芯 FFE9A8
怎么反馈：直接选 A / B / C / D，也可以混搭（例如「D 的像素 + B 的腮红」「去掉蜡泪」「眼睛大一格」）。 选定后我会出定稿稿：尺寸三档（小/中/大）+ 深浅壁纸完整验证 + 火苗摇曳帧（3~4 帧）+ reduced-motion 静态帧， 然后按定稿色值升级占位层、定义蜡烛部件池。
