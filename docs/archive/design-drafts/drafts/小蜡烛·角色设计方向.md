# 桌面宠物角色设计方向 · 小蜡烛

> 状态：**已归档（2026-10-25 角色层重启）**。小蜡烛降级为拟物物件方向的候选之一，物种决策见《缝隙居民·物种族群设计稿.md》；本文保留为该方向的探索成果，其中的动作语义映射与网格修订条目继续有效。
> 依据：《桌面宠物产品与视觉方向决策稿.md》《宠物世界观·v1最小设定.md》。
> 修订：形态曾探索「抽象光团（光团萤火）」，后按「从现实生物/物件衍生」的要求收敛为拟物小蜡烛；火苗保留了暖光灵魂。2026-10-25 推翻 25×50/7 色「精灵即代码」管线：程序不压缩美术资源，正式美术以分层位图交付、领养时离线合成（见 §3）。

## 1. 一句话

从屏幕缝隙里探出来的一小截奶油色蜡烛，火苗是它的生命状态——亮是清醒，暗是睡着，但它永远不会烧完。

## 2. 已确认的设计决策

| 维度 | 结论 |
|---|---|
| 形态 | 拟物小蜡烛：奶油色蜡身 + 顶部暖橙火苗，点眼在蜡身正面 |
| 性格 | 安静观察者：发呆、观察、睡觉，有反应但不讨好 |
| 配色 | 暖色奶感：奶油/奶白蜡身 + 暖橙火苗；基准稿色值已提取（§7），随视觉稿迭代 |
| 表情 | 点状眼 + 偶尔眨眼；嘴部有无待视觉稿 |
| 物种 | 无物种：蜡烛是物件不是生物，不与「不绑定现实物种」冲突 |
| 存在感 | 小而克制，桌面上不抢注意力 |

**物种设计公式**：未来新物种沿用同一方法——优先从现实生物/物件衍生拟物化（候选方向：蘑菇、茶宠、蜗牛、不倒翁、萤火虫等），每个物种自带独立部件池，架构详见《宠物个体生成规格.md》「角色层与个体层」一节。

## 3. 形态细节方向

- **网格规范（2026-10-25 修订，废除原 25×50/7 色定稿）**：精灵分辨率与色数由正式基准稿定稿时决定，程序不得对美术资源做降采样或量化压缩；随机所需的色板分组由美术稿的分层方式承载。显示时最近邻整数倍放大，禁止平滑插值。
- **精灵即资产（取代「精灵即代码」）**：正式美术以分层位图源稿交付（每物种自声明槽位；小蜡烛 = 蜡身/火苗/眼/蜡泪/托盘/小装饰），导出部件帧后由生成器在领养时按 seed 离线合成并缓存完整帧，运行时只渲缓存帧；候选预览与桌面窗口同源，所见即所得。现行 `pet_sprite_data.rs`/`gen_sprites.py` 索引管线降级为占位，正式美术接入时退役。
- **个体随机 = 部件选择 + 色板组替换**：蜡身色板组、火苗色板组整组替换，蜡泪/托盘/小装饰按部件池选择；描边与眼不参与随机。候选预览与桌面窗口共用同一套合成结果。现行索引管线下的色板表替换为占位实现。
- 蜡身：矮圆柱，下缘微宽坐得稳，轮廓圆润；正面点眼。
- 火苗：生命状态指示器——大小、亮度、摇曳幅度表达清醒度；火苗本身不画表情。
- **设计红线：永不烧短**。蜡身长度恒定，火苗只表达状态、不表达寿命；杜绝「燃尽=死亡」隐喻。蜡烛也不会随时间"变矮"或"流泪变少"。
- 可选手作感细节（待视觉稿）：侧面一两道凝固蜡泪痕、底部浅托盘。
- 无手无脚；移动=底部小碎步蹭行，火苗随步伐轻晃。

## 4. 动作语义映射（10 语义 × 蜡烛表现）

| 语义 | 表现方向 |
|---|---|
| `idle` | 火苗轻轻摇曳（幅度很小），偶尔眨眼 |
| `watch` | 眼睛随光标移动，火苗微微倾向光标方向 |
| `walk` | 小碎步蹭行，火苗随步伐晃动 |
| `sleep` | 火苗变暗变矮几乎熄灭，只剩一粒豆大的微光，眼睛闭合 |
| `wake` | 火苗重新立起变亮，眼睛睁开 |
| `poked` | 火苗猛地窜高一下随即回落，眼睛圆睁 |
| `petted` | 火苗变暖变亮 + 眯眼 |
| `notify_result` / `notify_attention` | 火苗轻跳 + 气泡 |
| `notify_warning` | 火苗明显蹿高偏橙红一瞬 + 气泡 |
| `hide` | 像被缝隙收回去一样，火苗先熄、蜡身渐隐 |

reduced-motion 静态替代：摇曳/晃动/渐变全部停用，用火苗大小档位（清醒大/睡眠小）和眼睛开闭表达状态。

## 5. 工程含义

- **占位层已切换为基准稿位图**（2026-10-20）：桌面窗口和领养预览外，宠物窗口直接渲染 candle-4 位图（等比缩放进 body 区域），描边、火苗、点眼均来自位图；命中区域按可见蜡身宽度收窄。
- 已知过渡态：① 位图眼睛是静态的，Watching 的眼神跟随暂被禁用，待位图按身体/火苗/眼睛分层后恢复；② 领养小窗预览仍是色块占位，与蜡烛形态的统一在生成器切换时一并处理。
- 像素动画（2026-10-20）：三帧位图换帧制——清醒帧 / 火苗偏摆帧（每 550ms 交替，偏摆帧裁掉的火焰顶部补淡暖余晖，不透出壁纸）/ 睡眠帧（火苗缩小变暗 + 5px 合成闭眼线）；reduced-motion 下停用摇曳只用清醒帧，状态切换仍即时。睡眠帧另保留整体 opacity 0.72 加强入睡感。
- 通知气泡继续用头顶占位气泡；样式待视觉稿统一。

## 6. 与世界观衔接

- v1 最小设定：「打开 Gesso，等于点亮了缝隙通往桌面的灯」——小蜡烛就是被点亮后留在桌面上的那盏小灯。
- 「屏幕亮是它的白天」：火苗与屏幕作息同呼吸；锁屏夜=火苗昏暗。
- 「它不会死，只会睡」：蜡烛不烧短是同一句话的形态化——光永远在，只是暗下去。
- 「不打扰工作」：一截小蜡烛的亮度克制，天然不吸睛。

## 7. 基准稿与定稿色值

**基准稿已选定：candle-4**（8 只候选中左右对称度最高，最符合「安静观察者」）；其余候选归档在 `docs/design/drafts/candle-candidates/`，随时可换。

| 色值 | 用途 |
|---|---|
| `#FFF6EF` | 蜡身奶白主体 |
| `#FFFCED` | 肩部高光 |
| `#661A0A` | 描边 / 点眼（深红棕） |
| `#FFAC04` | 火苗主橙 |
| `#FF6D00` | 火苗深橙 |

基准稿位图已作为占位层资产入库：`crates/app/assets/pets/candle-placeholder.png`。
