# Gesso 界面与交互设计规格 v1.0

> 模式：**Operate**（工具服务于任务，界面消失于任务）。配套：[DESIGN.md](DESIGN.md) · [技术方案.md](技术方案.md)
> 用户决策（2026-02）：轻量工具定位 · 中文默认+i18n 预留 · 跟随系统双主题 · 托盘常驻

---

## 0. 设计立场

**糙感检查**：壁纸工具的失败模式不是平淡，而是"每个控件都微妙地不对劲"。用过 WE/Lively/Raycast 的用户应该第一眼就信任每个控件——工具退到壁纸后面。

**工艺基准**（craft bar，建议值，可在确认轮修正）：Raycast 的面板纪律 + Linear 的密度与键盘 + 系统设置的双主题克制。**低于此基准的细节不许出厂。**

**反目标（v1 明确不做）**：标签系统、收藏夹、轮换播放列表、批量多选管理、向导跳过后的反复骚扰、模态优先、装饰性动效。轻量是定位不是妥协。

## 1. 视觉世界（已锁定）

**世界**：跟随系统的原生专业工具。中性灰阶为骨，单一强调色只做三件事——主操作、当前选中、状态指示。壁纸预览（全饱和、动态）是画面里唯一的彩色，**界面越安静，壁纸越出彩**——这是本产品视觉的底层逻辑。

### 1.1 语义色（双主题各一套 token，值在实现时以系统灰阶校准）

| Token（语义） | 亮色基准 | 暗色基准 | 用途 |
|---|---|---|---|
| `bg/surface` | 白 #FFFFFF | #1E1E20 | 内容区底 |
| `bg/panel` | #F5F5F7 | #26262A | 侧栏 / 工具条 |
| `bg/elevated` | #FFFFFF + 阴影 | #303034 | 弹出菜单 / 下拉 |
| `text/primary` | #1D1D1F | #EBEBED | 主文本 |
| `text/secondary` | #6E6E73 | #9B9BA1 | 次文本 / meta |
| `accent` | #316EF5（系统蓝系） | #5B8DEF | 主操作 / 选中 / 状态 |
| `accent/soft` | 蓝 12% 透明度 | 蓝 18% | 选中底、悬停底 |
| `danger` | #D33A3A | #E5545B | 失效 / 破坏性操作 |
| `border/hairline` | #E5E5EA | #3A3A3F | 1px 分隔线 |

规则：**强调色禁止用于装饰**。危险红只表达真实故障（素材失效），不用于确认按钮。

### 1.2 排版

- **单一 sans 家族，系统栈**：macOS = SF Pro（GPUI 默认即系统字）；Windows = Segoe UI Variable。不引入自定义字体——原生工具的字体即身份。
- 固定字号阶梯（比例 1.16）：`12`（meta/角标）、`13`（正文/控件，**基准**）、`15`（区块标题）、`20`（页面标题，仅向导用）、`28`（仅向导欢迎页一句话）。
- 数字等宽变体（tabular figures）用于 FPS、时长、分辨率。

### 1.3 图标

线性、单色、1.5px 描边、圆角端点，16px（行内）与 20px（工具条）两档。**不用 emoji**。播放/暂停/显示器/设置等标准件直接采系统意象（不逐像素复制系统图标，但语义与视觉重量对齐）。

### 1.4 动效纪律

150–250ms，`ease-out`。动效只表达状态变更：面板展开、指派切换时缩略图淡入、暂停指示出现。**禁止**：页面加载编排、壁纸卡片的装饰性循环动画、非状态性的任何弹跳。

## 2. 窗口模型与信息架构

```text
┌ 托盘（常驻，产品真正的主界面）
│   左键 / 右键 → 原生菜单（暂停 / 随机换一张 / 管理窗口 / 自启 / 退出）
│
└ 管理窗口（880×600 默认，420–1100px 自适应，关闭=隐藏）
    顶栏：产品名 + 三页签（壁纸库 · 显示器 · 设置） + 窗口控制
    │
    ├ 壁纸库（默认页）
    ├ 显示器
    └ 设置
```

- 三页签而非侧栏：轻量定位下只有三个目的地，页签少一次认知跳转。
- 主窗口最窄 420px 时页签退化为图标。

> **2026-10-11 变更（壁纸窗可见性语义，v3 定稿）**：显示器重配（唤醒/解锁/插拔/改分辨率/主屏切换/合盖开盖）期间，不变量是「**可见的壁纸窗必须与当前拓扑一致**」：几何未变的屏保持旧画面继续播放；几何已过时（显示器模式切换/重锚/移除）的窗口在事件后 ~30ms 内熄灭，由过渡窗静帧兜底，拓扑跨采样稳定后以原子切换施加新几何并点亮（新接入屏 ≈2s）。过渡几何（半程枚举的小窗/超大帧/放大裁切）从构造上不可见。

> **2026-10-12 变更（托盘「恢复系统壁纸」语义升级，v1.1 反馈「点击无效果」）**：只恢复系统桌面图用户看不见——壁纸窗还盖在上面。语义升级为**释放**：清空全部显示器指派（落盘）+ 拆除全部壁纸窗，桌面即回到用户自己的壁纸；重新指派才再上壁纸（下次启动不自动重建）。
>
> **2026-10-13 终局变更（过渡窗重构，三轮卡顿排障定案）**：接管机制整体移除——macOS 壁纸代理 FIFO 每张 5–16s、拥塞时 setDesktopImageURL 实测 2s，任何运行时写入都在主线程制造 UI 冻结，且静帧永远来不及在间隙内渲染（收益从未兑现）。重配无缝改由**自家过渡窗**承担：清扫几何过时屏前先上静帧窗（预解码帧，毫秒级），真窗点亮后撤。运行时**永不写系统桌面**（稳态桌面=用户自己的壁纸，无需开关，无需恢复/沉降等待）；旧版残留由启动一次性清理；设置开关移除。已知取舍：图片类条目（非 PNG 源）无解码器，其重配间隙退回露出用户壁纸（v1）。

## 3. 全局组件规格

每个交互组件六态齐全：**default / hover / focus / active / disabled / selected**（+ 上下文态 loading / error）。同一动词在所有页签里长一样。

| 组件 | 规格 |
|---|---|
| **按钮** | 高 28px（紧凑 24px）。主按钮 = accent 实底白字；次按钮 = panel 底 + hairline 边；文字按钮 = 无底。圆角 6px |
| **开关** | 系统开关规格（36×20），状态色 = accent |
| **下拉** | 原型 28px；实现映射 kit Small 24px（kit 无 28 档，见 §1.2），右侧 chevron，展开 elevated 底 + 阴影，键盘 ↑↓↵ |
| **输入框** | 原型 28px；实现映射 kit Small 24px，focus = accent 1.5px 外描边（不发光） |
| **右键菜单** | elevated 底，8px 圆角，阴影，分隔线分组；破坏项红字置底 |
| **卡片** | 见 §4.3 卡片解剖 |
| **角标** | 10px 等宽大写，如 `VIDEO` `WE`，hairline 描边胶囊（行高 16px；与原型一致） |
| **气泡通知** | 应用内 toast（kit Notification，窗口右上角弹出）：标题 + 一行正文，自动消失；托盘本身不弹气泡 |

**键盘模型**（管理窗口）：
- `Tab` 走焦点环（focus 环 2px accent，永远可见，不尊重"focus-visible 折叠"——工具类应用键盘是公民）
- `←/→` 或 `1/2/3` 切页签；`F` 聚焦搜索；`Esc` 清空搜索 / 关闭弹出层
- `Cmd/Ctrl+,` → 设置页（工具惯例）
- 库网格方向键移动、`↵` 指派、`Space` 预览定格：**未实现**（v2 候选；当前指派路径 = 双击/右键/拖拽）

## 4. 逐屏规格

### 4.1 托盘 · 菜单（Windows：左键开主窗口 / 右键菜单）——高频操作的家

> **2026-10-03 变更（用户决策）**：撤销 v1.0 的「左键快速面板」（独立弹出小窗）。
> 理由：浮动窗口不锚定托盘图标，观感突兀；WE/Plash 同类均为纯菜单形态。
> 本节原缩略图面板规格作废；signature #3 一并撤销（DESIGN.md 同步）。
>
> **2026-11-10 修订（用户决策）**：Windows 托盘左键单击 = 立即打开/激活管理主窗口，
> 右键才弹菜单——「两击完成高频操作」升级为「一击直达」。开的是已有的主窗口本体，
> 不是新造浮动面板，不复活被撤销的快速面板。macOS 菜单栏图标没有右键概念，保持
> 单击弹菜单，开窗走「管理窗口…」项。同轮菜单结构优化：图标 + 分组 + 状态文案。

```text
管理窗口…                        ← 首项：Windows 左键点托盘直达的就是它
暂停全部壁纸 / 恢复全部壁纸        ← 按当前状态二选一（2026-11-10：文案随暂停状态切换，主循环重建菜单，与语言/自启变化同机制）
随机换一张                        ← 主显示器随机指派一张（真随机排除当前；2026-10-13 前实为顺序循环）。无会话时（如「恢复系统壁纸」释放后）回退主显示器重新随机指派
─────────────────
检查更新…                        ← 2026-10-11 新增（§4.7）：打开/激活更新小窗
─────────────────
开机自启               ✓         ← 勾选项，即点即生效
─────────────────
恢复系统壁纸                      ← 2026-10-11 新增 / 2026-10-12 语义升级：清空全部显示器指派并拆除全部壁纸窗，桌面即回到用户自己的壁纸（运行时不接管系统桌面，无需还原动作）
─────────────────
退出 Gesso
```

- 系统原生菜单（muda）。Windows：左键开主窗口（`menu_on_left_click(false)` +
  `TrayIconEvent`，入队 `FocusMainWindow`，与「管理窗口…」同一动作）、右键弹菜单；
  macOS：单击弹菜单不变
- 菜单项图标（2026-11-10 新增）：与品牌图形同源的 Lucide 线稿单色 PNG
  （muda `IconMenuItem`）；平台不支持时降级为纯文字项，结构不变
- 「管理窗口…」置顶（高频第一）；「恢复系统壁纸」与「退出 Gesso」之间加分隔——
  误触不再连坐
- macOS 使用菜单栏常驻应用策略：不出现在 Cmd+Tab 应用切换器；点「管理窗口…」或「检查更新…」仍直接激活对应窗口。管理窗口设为
  MoveToActiveSpace：激活时弹到用户此刻所在的桌面（而非把用户拽到窗口所在的桌面）
- **设计意图**：Windows 一击直达主窗口，其余高频操作两击完成；预览靠主窗口，托盘只做动作。

### 4.2 托盘 · 右键菜单

> 2026-11-10 起 Windows 左键开主窗口、右键弹菜单（macOS 单击弹菜单不变），
> 本节不再单独维护——当前菜单规格见 §4.1。

### 4.3 壁纸库页（默认页）

```text
┌──────────────────────────────────────────────────────┐
│ Gesso   [壁纸库] [显示器] [设置]                 – □ ✕ │ ← 顶栏 44px
├──────────────────────────────────────────────────────┤
│ [全部|视频|动图|图片|Shader|网页|WE]  🔍搜索___ [+导入▾] │ ← 工具条 48px（含后续新增的图片分类）│
├──────────────────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐          │
│ │ 预览区  │ │        │ │        │ │        │          │ ← 卡片：响应式等分
│ │        │ │        │ │        │ │        │          │   minmax(196px,1fr)，
│ ├────────┤ ├────────┤ ├────────┤ ├────────┤          │   列数随窗口宽度适配、
│ │▐nebula ▸│ │waves   │ │clock   │ │sakura WE│         │   撑满整行不留尾空
│ │VIDEO 4K│ │SHADER  │ │WEB     │ │WE·VIDEO│          │   (16:9 预览+56px 信息条)
│ └────────┘ └────────┘ └────────┘ └────────┘          │
│      …（滚动）                                         │
├──────────────────────────────────────────────────────┤
│ 128 项 · WE 34 · 双击卡片设为壁纸 · 拖入文件导入          │ ← 状态条 28px
└──────────────────────────────────────────────────────┘
```

**卡片解剖**（信息条 56px）：
- **网格响应式**（原型 `.wall-grid`：`repeat(auto-fill, minmax(196px, 1fr))`）：列数随窗口宽度适配，同行卡片等分撑满整行、不留尾空；固定 208px + wrap 的实现已废弃（放不下时右侧留大空）
- **排序 = 插入时间倒序**（2026-11-08）：最新入库的卡片排最前（清单插入序 = 时间序），导入后第一眼可见；内置样例最早注册，自然沉底
- 网格四周留边一致（2026-11-08）：滚动区底距 = 左右 14px，末行不贴状态条
- 左 3px 指示条：已指派到某显示器 = accent；失效 = danger；未指派 = 无
- 名称（13px primary，超长省略）+ 右侧角标（类型 `VIDEO/SHADER/WEB/GIF/PHOTO` + 来源 `WE`）；角标 `flex:none`、信息条行间距 1px 且行级不裁剪（对齐原型 `.badge{flex:none}`/`.info{gap:1px}`/`.row1` 无 overflow——gpui 默认行高偏大，行级 overflow 曾把角标 1px 描边裁掉，2026-11-08）
- meta 行（12px secondary，tabular）：分辨率 · 时长/帧率 · 指派目标（"→ 主屏"）

**交互**：

| 动作 | 行为 |
|---|---|
| 悬停卡片 | 预览自动播放（视频抽帧动图 / shader 定时截图序列；实现见 §6 spike）；已指派时**显示器页对应小像点亮 2px accent 描边**（悬停 = 瞬时、点选 = 跨页常驻，见 4.4；真实桌面边缘从未实现——v1 曾规划透明描边窗，v1.1 起指认语义收敛到应用内） |
| 单击 | 选中（accent/soft 底），状态条显示该卡片 meta 详情；**选中即跨页指认**（2026-11-08）：显示器页对应屏常驻点亮 2px accent 描边——悬停指认是瞬态（鼠标离开卡片即清，跨页不可见），选中态才能跨页看见「我选的壁纸在哪块屏上」 |
| 双击 / `↵` | 指派到**当前目标屏**——处于「为选屏挑壁纸」流程时 = 该屏；否则 = 主显示器（默认），托盘气泡确认 |
| 右键 | 菜单：设为壁纸 →（子项：主屏/副屏/全部）· 打开所在目录 · ── · 从库中移除（红字，二次确认内联在菜单项里展开；local 拷贝条目连库内目录一并删除，WE/url 只断引用，见 §7。「查看详情」已于 0.1.1 移除——只是重复卡片上已有的三条信息） |
| **拖拽卡片 → 显示器页拓扑** | 直接指派到目标屏（跨页签拖拽；signature 交互） |
| 拖入文件 | 窗口任意位置接受 mp4/webm/gif/webp/html/glsl，导入+选中+气泡；不支持类型 → 状态条红字说明原因（HEVC 提示装扩展、mkv 提示转封装） |
| 点击 [+ 导入] | 弹出锚定菜单（单一「新增内容」入口）：**导入文件…**（打开文件对话框，与拖拽同路径）/ **从 URL 导入网页…**（打开 URL 小窗）。主路径零层级；菜单项语义 = 把新内容弄进库 |
| 搜索 | 标题/标签模糊匹配，即时过滤，`Esc` 清空 |

> **2026-11-07 变更（「为选屏挑壁纸」流程，修复副屏指派断头路）**：显示器页未指派屏的
> 「选择壁纸」（小像 / 详情条）与已指派屏的「更换」进入目标屏流程——**记录目标屏后跳库页**，
> 库页状态条出现横幅「正在为 {屏名} 选择壁纸 · 双击卡片指派到该屏 · [取消]」；双击卡片 =
> 指派到目标屏（无流程时 = 主显示器，原语义不变）；任何指派成功或点 [取消] 后流程结束，
> 目标屏拔出则横幅自动消失。此前双击恒指主屏、跳转丢失目标屏，从副屏进入库页后无法给
> 副屏指派（实测根因；右键菜单与拖拽指派不受影响）。

**筛选条**：单选段控件；`WE` 筛选仅在已导入 WE 条目时出现（无扫描——WE 只由用户主动导入）。

**空状态**（区分三种，按「库空? × 搜索词? × 筛选后空?」分派）：
- *首启未导入*（库为空，无论有无搜索词）：居中插画位（简线风格）+「把第一张壁纸拖进来，或 [导入文件] / [浏览内置样例]」（两个真按钮，不是死链接）
- *搜索无结果*（库非空 + 搜索词非空 + 筛选后空）：「没有匹配"xxx"的壁纸 · [清除搜索]」
- *筛选为空*（库非空 + 无搜索词 + 筛选后空；2026-10-07 补）：
  标题「还没有 {label} 壁纸」（label = 类型名或 WE）；WE 筛选附出路描述
  「导入时选择 Wallpaper Engine 的 project.json，即可以零拷贝引用进库」；
  动作 = [查看全部壁纸]（切回「全部」筛选）——无搜索可清，不放 [清除搜索]

**错误状态**：失效卡片信息条红字 `文件已移除`，预览区降级为灰底问号图标；右键菜单"从库移除"置顶。**预览区永不白屏。**

> **2026-10-07 变更**：新增远端网页条目（origin=`url`）。
> - 入口收敛（同日两步：先加 🔗 独立钮，经工艺复查收敛为**单一「+ 导入」菜单钮**——
>   图标幽灵钮与带字钮并排重量失衡、双入口语义重复、tooltip 依赖可发现性差；
>   反目标「模态优先」亦不允许再加独立窗体入口）。URL 小窗保留为菜单项落点，

### 4.7 软件更新（2026-10-11 新增；2026-11-10 修订交付体验）

GPUI + wry 栈无现成 updater 插件可引；更新子系统自建
（`crates/app/src/update.rs`）。v1 交付形态 = **下载官方安装包 + 交由系统安装**
（dmg 挂载 / setup.exe 运行），**不做静默自替换**：ad-hoc 签名 + 无 Sparkle/Winsparkle
基建，自替换的失败模式（半写入损坏、签名失效、失败无法回滚）远超其收益。

> **2026-11-10 修订**（升级体验走查：下载完还要手动点「打开安装包」，点完应用也不退，
> gesso.exe 被运行中进程锁住还会让安装器弹「重试/中止」）：下载完成 → 5 秒倒计时
> 自动启动安装包并优雅退出；release notes 按 markdown 渲染（此前 `##`/`**` 标记
> 原样上屏）；小窗高度随状态收紧，去掉大片空白；安装器装完自动拉起 Gesso，升级
> 闭环。自动安装仍是「把官方安装包交给系统跑」，不是静默自替换，上述红线不变。

**检查策略**

- 数据源：GitHub Release 资产 `latest.json`（通过 `releases/latest/download/` 获取，
  不访问限流的 REST API）；清单不可用时显示失败出路，不自动切换到 API。`version`
  按语义版本三元组比较，任一侧解析失败保守判定「无更新」，绝不拿坏数据提示用户。
  发布说明保留兼容旧客户端的 `notes`，新客户端优先读取 `notes_localized.zh/en`，
  按当前 App 语言显示，缺少对应语言时回退到另一份。
- 时机：启动 ≈15s 后静默首查 + 每 24h 一次；设置页按钮与托盘菜单可手动触发
  （手动不受 24h 抑制，但与进行中的检查/下载互斥，忙时忽略重复触发）
- 开关：设置页「自动检查更新」默认开（`settings.update_check`，仅约束自动检查）

**有更新时的通知（多层递进，各层独立，互不阻塞）**

1. 系统通知（best-effort）：macOS 走 osascript（免 bundle/签名限制，开发裸进程也能弹）；
   Windows 走 toast（依赖 AUMID，Inno 安装版有效；便携 zip 未注册时静默降级）
2. 应用内 toast（管理窗口存在时推送一条）
3. 托盘 tooltip 变为「Gesso — 新版本 v* 可用」（回到无更新态即复原）
4. 设置页「关于与更新」组常驻显示新版本号 + [查看…] 入口

**更新弹窗（紧凑小窗，标题「Gesso · 软件更新」）**

一窗承载全部状态，状态真源在更新模块全局（含倒计时截止时刻），随引擎快照刷新
（无独立定时器）；「暂不安装」「立即安装」等写操作入队引擎动作，倒计时剩余秒数
随既有 update 快照回灌：

| 状态 | 内容 | 按钮 |
|---|---|---|
| 检查中 | 转圈 + 「正在检查更新…」 | — |
| 已最新 | 「Gesso vX.Y.Z 已是最新版本」 | 关闭 |
| 发现新版本 | 新版本号 + release notes（markdown 渲染，限高滚动）+ 安装包名 · 大小 | 稍后 / 前往发布页 / **下载更新** |

- release notes 渲染：markdown 子集 = `##`/`###` 标题、`-` 无序列表、段落、
  行内 `**粗体**`（发布说明模板只用这些）；子集之外的标记按纯文本降级。
  解析为纯函数 + 单测（放 `crates/app`，与 `parse_manifest`/`pick_asset` 同先例），
  渲染在 `update_view`，不引第三方 markdown 库

**倒计时自动安装（2026-11-10 修订核心）**

- 下载完成即进入 5 秒倒计时；归零 = 启动安装包 + 走 `EngineAction::Quit` 优雅退出

  安装器随后覆盖 `gesso.exe` 才不会撞上文件占用弹「重试/中止」；spawn 出的安装器

- 「立即安装 (N)」跳过剩余等待直接执行；「暂不安装」停在下载完成态，退回手动

- macOS 同语义：倒计时归零挂载 dmg（`open`）后退出应用；静默自替换红线不变
- 安装器侧兜底与闭环（`packaging/windows/gesso.nsi`）：`.onInit` 检测运行中的
  gesso.exe，等待其退出再继续（防双开竞争）；安装完成自动拉起 Gesso，装完即回新版本
- 安装包选择：macOS 取含本机 arch 的 `.dmg`（无 arch 匹配退回任意 dmg）；
  Windows 优先 `<arch>-setup.exe`（安装版升级路径明确，且注册 AUMID 供通知），
  无则 `<arch>-portable.zip`
- 下载落 `<配置目录>/update/`，先写 `.part` 成功后原子改名；应用启动时清空该目录
  （残留半成品/旧安装包不跨会话保留）

### 4.8 锁屏快照同步（2026-11-07 立项；Windows 2026-11-08 实现、macOS 2026-11-09 实现（见 §4.8.1）；默认关）

Windows 侧：把主屏壁纸的静态帧同步为 Windows 锁屏图，对齐 Wallpaper Engine「Override lock
screen image」的行业先例。OS 限制：**Windows 锁屏只接受静态图**——动态内容在
锁屏上的上限就是静帧快照。走官方 `Windows.System.UserProfile.LockScreen` API，
**不写系统桌面**（红线不动；锁屏图是独立 OS 表面，见 ROADMAP「明确不做」区分行）。

**开关（设置页「联动（实验）」组，`settings.lockscreen_sync`，默认关）**

- 开关语义：**打开 = 锁屏进入 Gesso 快照模式；关闭 = 恢复打开前的锁屏设置**。
  文案只说模式切换，不说「替换每日一图」这类副作用（用户决策 2026-11-07）
- **即指即得（封面帧）**：每张壁纸入库时按主屏分辨率生成一张固定封面帧
  （后台，JPEG，上限 4K；jpg/png 静图直接引用主文件）。指派/打开开关 =
  把现成封面贴上锁屏，毫秒级，无抓帧无编码。抓帧放导入时而非指派时——
  同一壁纸的锁屏形象从此固定（不再随指派时机抓到不同瞬间）
- 兜底：旧条目 / 封面生成失败 → 首次指派时活窗抓一帧（存为该条目缓存，
  下次即用）
- 关闭开关 = **立即还原**；托盘「恢复系统壁纸」与退出同语义
- 「还原」= 恢复打开前的锁屏设置：记录覆盖前的模式（Windows 聚焦 / 用户自选图片）
  与图片路径，照原样恢复。OS 行为：写入快照会把锁屏切到「图片」模式，切回聚焦
  依赖半公开注册表机制（探针已实测可行）；原图片被外部工具删除时仅回切模式
- 不可用态：探测失败（WinRT 运行时缺失 / 组策略限制）→ 不渲染开关 + 一行原因
  说明（如「此系统不支持设置锁屏图」），一次性探测、不重试、不报错

**触发与更新**

- 指派（含「指派到全部」）与开关打开 = **即时应用**（封面帧入库时已就绪，
  毫秒级 WinRT 调用）；另排 ≈1s 防抖全量同步兜底收敛中的变化。后台线程执行，
  不在任何交互路径（与 2026-10-13 桌面桥接教训相反的结构：一次性后台写，
  非高频跨进程投递）；桌面（Space）切换的补写走防抖（macOS，低频用户动作）
- 快照恒取**主屏**当前壁纸的封面帧（锁屏是单图表面，多屏指派也只看主屏）
- 主屏无指派（释放态）= 不产生新快照；「恢复系统壁纸」触发的还原见上一节

**状态矩阵**

| 场景 | 锁屏表现 |
|---|---|
| 开关开 + 主屏有壁纸 | 主屏壁纸静态帧 |
| 开关开 + 主屏无壁纸（释放） | 还原用户原锁屏设置 |
| 开关关 | 用户原锁屏设置（聚焦/图片，Gesso 不触碰） |
| 不可用机器 | 开关置灰，锁屏永不被触碰 |

技术方案见 `技术方案.md` §9。文案原则见 §7：开关描述只说「打开=壁纸快照，
关闭=恢复原设置」；模式切换是 OS 内部行为，进技术方案，不进用户文案。

### 4.8.1 macOS 锁屏快照（2026-11-08 立项，2026-11-09 已实装并实机验证；默认关）

macOS 锁屏背景 = 当前桌面壁纸（无独立表面、无公开锁屏 API，调查全文见
技术方案 §10）。因此 macOS 的实现方式是：**把系统桌面壁纸换成主屏壁纸的
封面帧**，锁屏随之显示。写入走官方 `NSWorkspace.setDesktopImageURL`，
一次性后台写（本机实测 1–3s 生效）；写入的是被 Gesso 钉窗盖住的桌面层，
用户平时不可见。

**开关**：与 Windows 共用同一开关（`settings.lockscreen_sync`，设置页
「联动（实验）」组，默认关），语义完全一致：**打开 = 锁屏进入 Gesso 快照
模式；关闭 = 恢复打开前的桌面壁纸**。

- **封面帧**：与 Windows 同源——每张壁纸入库时生成的 `thumb_home/poster.jpg`
  （jpg/png 静图直接引用主文件），零抓帧即指即得
- **多桌面（Space）跟随**：macOS 壁纸按桌面各存一份，单次写入只覆盖当前
  桌面。开关开着时监听桌面切换（`NSWorkspace` 官方通知），每次切换给新
  桌面补封面帧（仍是防抖后一次性低频写）；换着桌面锁屏，锁屏恒为封面帧
- **四路还原**：关闭开关 / 托盘「恢复系统壁纸」/ 移除条目 / 退出时写回原
  壁纸；簿记 = 首次写入前记录原壁纸 URL + 缩放/裁剪/底色选项 + **已写桌面
  清单**（`mac_lockscreen_backup.applied`，去重追加）。还原按清单逐桌面
  清扫：当前桌面命中清单才写回，写回后划掉，清空才清簿记；未命中的桌面
  保留簿记，换桌面时继续清，退出未清完的下一次启动继续。应用启动时桌面
  若残留 Gesso 封面帧（上次异常退出）→ 照簿记清理恢复
- 不可用态：macOS 上该 API 全系统可用，无置灰场景（探测恒过）

**状态矩阵（macOS）**

| 场景 | 锁屏 / 桌面表现 |
|---|---|
| 开关开 + 主屏有壁纸 | 桌面壁纸层 = 封面帧（被钉窗盖住），锁屏显示封面帧 |
| 开关开 + 切换桌面 | 新桌面壁纸层被补写为封面帧，锁屏仍为封面帧 |
| 开关开 + 主屏无壁纸（释放） | 还原用户原桌面壁纸，锁屏随之恢复 |
| 开关关 | 命中「已写清单」的桌面逐个恢复原壁纸；未覆盖的桌面 Gesso 不触碰 |
| 异常退出后启动 | 启动清理：残留封面帧恢复为簿记原壁纸，随桌面切换继续清完 |

**已知取舍（实机验证后回改）**：① 视频条目在锁屏上显示封面帧（视频动态
上锁屏 = 系统壁纸扩展，路线 A——**已搁置**，因需付费开发者签名身份，见
技术方案 §10，详情存档 docs/archive/锁屏方案调查与路线A-M1-2026-11.md）；② 各桌面壁纸本不相
同的场景，还原统一恢复为打开时记录的那一张原壁纸——公开 API 无法按桌面
备份（写入只落当前桌面，且无公开的桌面枚举/标识），这是官方 API 路线的
硬边界；③ 未访问到的桌面在本次会话内不会被还原，由下次启动清理收敛。

技术方案见 `技术方案.md` §10。

## 7. 文案原则（中文）

- 直说，不拟人：「暂停全部壁纸」不是「让桌面休息一下」
- 失败文案带原因和出路：「HEVC 视频需要系统安装 HEVC 扩展（Microsoft Store 免费）」
- 数字用 tabular，单位前置：「4K · 12s · → 主屏」
- 危险操作动词精确：「从库中移除」永远不说「删除」。移除语义（2026-10-07 变更）：
  **local/builtin 拷贝条目 = 连同库内拷贝目录移入系统回收站/废纸篓（可恢复）**；
  WE 零拷贝引用与远端网页条目的源永不在我们手里，移除只断引用。
  回收站不可用则保留原地，绝不回退为永久删除。toast 不再承诺「文件未删除」
