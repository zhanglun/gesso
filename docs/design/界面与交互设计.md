# Gesso 界面与交互设计规格 v1.0

> 模式：**Operate**（工具服务于任务，界面消失于任务）。配套：[PRODUCT.md](PRODUCT.md) · [技术方案.md](技术方案.md) §3.7/§3.8
> 用户决策（2026-02）：轻量工具定位 · 中文默认+i18n 预留 · 跟随系统双主题 · 托盘常驻

## 0. 设计立场

**糙感检查**：壁纸工具的失败模式不是平淡，而是"每个控件都微妙地不对劲"。用过 WE/Lively/Raycast 的用户应该第一眼就信任每个控件——工具退到壁纸后面。

**工艺基准**（craft bar，建议值，可在确认轮修正）：Raycast 的面板纪律 + Linear 的密度与键盘 + 系统设置的双主题克制。**低于此基准的细节不许出厂。**

**反目标（v1 明确不做）**：标签系统、收藏夹、轮换播放列表、批量多选管理、向导跳过后的反复骚扰、模态优先、装饰性动效。轻量是定位不是妥协。

## 1. 视觉世界（已锁定）

**世界**：跟随系统的原生专业工具。中性灰阶为骨，单一强调色只做三件事——主操作、当前选中、状态指示。壁纸预览（全饱和、动态）是画面里唯一的彩色，**界面越安静，壁纸越出彩**——这是本产品视觉的底层逻辑。

### 1.1 语义色（双主题各一套 token，值在实现时以系统灰阶校准）

| Token（语义） | 亮色基准 | 暗色基准 | 用途 |
|---|---|---|---|
| `bg/surface` | 白 #FFFFFF | #1E1E20 | 内容区底 |
| `bg/panel` | #F5F5F7 | #26262A | 侧栏 / 工具条 |
| `bg/elevated` | #FFFFFF + 阴影 | #303034 | 弹出菜单 / 下拉 |
| `text/primary` | #1D1D1F | #EBEBED | 主文本 |
| `text/secondary` | #6E6E73 | #9B9BA1 | 次文本 / meta |
| `accent` | #316EF5（系统蓝系） | #5B8DEF | 主操作 / 选中 / 状态 |
| `accent/soft` | 蓝 12% 透明度 | 蓝 18% | 选中底、悬停底 |
| `danger` | #D33A3A | #E5545B | 失效 / 破坏性操作 |
| `border/hairline` | #E5E5EA | #3A3A3F | 1px 分隔线 |

规则：**强调色禁止用于装饰**。危险红只表达真实故障（素材失效），不用于确认按钮。

### 1.2 排版

- **单一 sans 家族，系统栈**：macOS = SF Pro（GPUI 默认即系统字）；Windows = Segoe UI Variable。不引入自定义字体——原生工具的字体即身份。
- 固定字号阶梯（比例 1.16）：`12`（meta/角标）、`13`（正文/控件，**基准**）、`15`（区块标题）、`20`（页面标题，仅向导用）、`28`（仅向导欢迎页一句话）。
- 数字等宽变体（tabular figures）用于 FPS、时长、分辨率。

### 1.3 图标

线性、单色、1.5px 描边、圆角端点，16px（行内）与 20px（工具条）两档。**不用 emoji**。播放/暂停/显示器/设置等标准件直接采系统意象（不逐像素复制系统图标，但语义与视觉重量对齐）。

### 1.4 动效纪律

150–250ms，`ease-out`。动效只表达状态变更：面板展开、指派切换时缩略图淡入、暂停指示出现。**禁止**：页面加载编排、壁纸卡片的装饰性循环动画、非状态性的任何弹跳。

## 2. 窗口模型与信息架构

```text
┌ 托盘（常驻，产品真正的主界面）
│   左键 / 右键 → 原生菜单（暂停 / 随机换一张 / 管理窗口 / 自启 / 退出）

    │

    ├ 显示器
    └ 设置

```

- 三页签而非侧栏：轻量定位下只有三个目的地，页签少一次认知跳转。
- 主窗口最窄 420px 时页签退化为图标。

## 3. 全局组件规格

每个交互组件六态齐全：**default / hover / focus / active / disabled / selected**（+ 上下文态 loading / error）。同一动词在所有页签里长一样。

| 组件 | 规格 |
|---|---|
| **按钮** | 高 28px（紧凑 24px）。主按钮 = accent 实底白字；次按钮 = panel 底 + hairline 边；文字按钮 = 无底。圆角 6px |
| **开关** | 系统开关规格（36×20），状态色 = accent |
| **下拉** | 28px 高，右侧 chevron，展开 elevated 底 + 阴影，键盘 ↑↓↵ |
| **输入框** | 28px，focus = accent 1.5px 外描边（不发光） |
| **右键菜单** | elevated 底，8px 圆角，阴影，分隔线分组；破坏项红字置底 |
| **卡片** | 见 §4.3 卡片解剖 |
| **角标** | 11px 等宽大写，如 `VIDEO` `WE`，hairline 描边胶囊 |
| **气泡通知** | 托盘气泡：标题 + 一行正文 + 一个动作链接，5s 自动消失；同类故障 60s 内去重 |

**键盘模型**（管理窗口）：
- `Tab` 走焦点环（focus 环 2px accent，永远可见，不尊重"focus-visible 折叠"——工具类应用键盘是公民）
- `←/→` 或 `1/2/3` 切页签；`F` 聚焦搜索；`Esc` 关闭弹出层
- 库网格：方向键移动、`↵` = 设为主显示器、`Space` = 悬停预览定格
- `Cmd/Ctrl+,` → 设置页（工具惯例）

### 4.3 壁纸库页（默认页）

```text
┌──────────────────────────────────────────────────────┐
│ Gesso   [壁纸库] [显示器] [设置]                 – □ ✕ │ ← 顶栏 44px
├──────────────────────────────────────────────────────┤
│ [全部|视频|动图|Shader|网页|WE]  🔍搜索___  [导入][🔗]   │ ← 工具条 48px
├──────────────────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐          │
│ │ 预览区  │ │        │ │        │ │        │          │ ← 卡片：响应式等分
│ │        │ │        │ │        │ │        │          │   minmax(196px,1fr)，
│ ├────────┤ ├────────┤ ├────────┤ ├────────┤          │   列数随窗口宽度适配、
│ │▐nebula ▸│ │waves   │ │clock   │ │sakura WE│         │   撑满整行不留尾空
│ │VIDEO 4K│ │SHADER  │ │WEB     │ │WE·VIDEO│          │   (16:9 预览+56px 信息条)
│ └────────┘ └────────┘ └────────┘ └────────┘          │
│      …（滚动）                                         │
├──────────────────────────────────────────────────────┤
│ 128 项 · WE 34 · 双击设为主显示器 · 拖入文件导入          │ ← 状态条 28px
└──────────────────────────────────────────────────────┘
```

**卡片解剖**（信息条 56px）：
- **网格响应式**（原型 `.wall-grid`：`repeat(auto-fill, minmax(196px, 1fr))`）：列数随窗口宽度适配，同行卡片等分撑满整行、不留尾空；固定 208px + wrap 的实现已废弃（放不下时右侧留大空）
- 左 3px 指示条：已指派到某显示器 = accent；失效 = danger；未指派 = 无
- 名称（13px primary，超长省略）+ 右侧角标（类型 `VIDEO/SHADER/WEB/GIF` + 来源 `WE`）
- meta 行（12px secondary，tabular）：分辨率 · 时长/帧率 · 指派目标（"→ 主屏"）

**交互**：

| 动作 | 行为 |
|---|---|
| 悬停卡片 | 预览自动播放（视频抽帧动图 / shader 定时截图序列；实现见 §6 spike）；已指派时**对应真实显示器边缘出现 2px accent 描边**（signature，见 4.4） |
| 单击 | 选中（accent/soft 底），状态条显示该卡片 meta 详情 |
| 双击 / `↵` | 设为**主显示器**壁纸，托盘气泡确认 |
| 右键 | 菜单：设为壁纸 →（子项：主屏/副屏/全部）· 打开所在目录 · 查看详情 · ── · 从库中移除（红字，二次确认内联在菜单项里展开） |
| **拖拽卡片 → 显示器页拓扑** | 直接指派到目标屏（跨页签拖拽；signature 交互） |
| 拖入文件 | 窗口任意位置接受 mp4/webm/gif/webp/html/glsl，导入+选中+气泡；不支持类型 → 状态条红字说明原因（HEVC 提示装扩展、mkv 提示转封装） |
| 点击 🔗（工具条） | 打开「从 URL 导入」小窗：粘贴网页地址 → [导入]。仅接受 https；缺 scheme 自动补 `https://`，无效地址输入框下红字内联提示。导入成功气泡确认，卡片进「网页」筛选 |
| 搜索 | 标题/标签模糊匹配，即时过滤，`Esc` 清空 |

**筛选条**：单选段控件；`WE` 筛选仅在已扫描时出现。

**空状态**（区分两种）：
- *首启未导入*：居中插画位（简线风格）+「把第一张壁纸拖进来，或 [导入文件] / [浏览内置样例]」（两个真按钮，不是死链接）
- *搜索无结果*：「没有匹配"xxx"的壁纸 · [清除搜索]」

**错误状态**：失效卡片信息条红字 `文件已移除`，预览区降级为灰底问号图标；右键菜单"从库移除"置顶。**预览区永不白屏。**

> **2026-10-07 变更**：新增远端网页条目（§4.3 工具条 🔗，origin=`url`）。
> - 卡片 meta 行显示来源域名（如 `louie.co.nz`）；类型角标仍为 `WEB`
> - 右键「打开所在目录」置灰（远端条目无本地目录）
> - 安全边界：仅 https；页面运行在宿主页沙箱 iframe 内（无顶页导航/弹窗/表单）；
>   暂停/降帧/光标桥为 best-effort（远端页面不监听则不配合，自动暂停仍会盖住画面）
> - 断网：该壁纸显示空白（沿用「预览区永不白屏」的降级底色）

### 4.4 显示器页

**桌面沙盘 + 详情条**（2026-10-04 改版：屏内控件移出，画布成为主体——显示器页的主角是"桌面本身"，参考 macOS/Windows 系统显示器设置的排布语法）：

```text
┌──────────────────────────────────────────────────────┐
│ 桌面沙盘（占满剩余高度；desk 渐变底 + hairline 内描边）      │
│  悬停库卡片时，对应显示器会亮起              [⟳ 重新检测]  │
│        ┌──────────────────────┐                      │
│        │ ▶ 播放中              │ ← 屏幕小像：等比、壁纸    │
│        │                      │   实时预览铺满、hairline   │
│        │   主显示器 1512×982   │   边框、真实投影          │
│        └──────────────────────┘ ← 底部渐变托底白字        │
│                                                      │
├──────────────────────────────────────────────────────┤
│ 主屏 1512×982  ▶ Fate-举剑 · 播放中    [更换][暂停][60 fps▾] │
│ 标识取自 EDID · 重新接入自动恢复                         │
└──────────────────────────────────────────────────────┘
```

**沙盘（画布）**：
- 按**工作区坐标等比铺排**：全部屏的包围盒适配画布（留边距、居中），保留物理相对位置；单屏时居中一块大屏（宽度上限约 0.6 画布宽，避免顶满）。
- **屏幕小像 = 纯屏幕**，不再是塞满控件的卡片：屏自身宽高比（非一律 16:9）、当前壁纸预览 cover 铺满（播放中=动态，暂停=定格）、hairline 边框 + 偏移软投影、底部黑色渐变托底放 名称+分辨率（白字，任何壁纸上可读）、左上状态胶囊（深色半透玻璃：状态图标+文案）。
- 未指派：hairline 虚线边 + muted 底 + 居中「＋ 选择壁纸」（点击跳库页）。
- 交互：悬停小像 = 投影抬升；悬停库卡片 → 对应小像 **2px accent 描边**（signature 双向指认）；点击小像 = 选中（详情条随之切换）；**拖拽库卡片到具体屏上放手 = 指派**（dashed accent 描边投放态）。

**详情条（画布下方，固定高）**：
- 左：屏短名 + 「主屏」角标 + 分辨率（tabular）+ 状态（图标+文案，与托盘一致）+ 第二行 11px 备注「标识取自 EDID · 重新接入自动恢复」。
- 右：`[更换]`（跳库页）`[暂停/恢复]`（真源 = 引擎 pause_one）+ FPS 下拉（60/30/15/5）。控件恒定尺寸——**不再塞进小像**（v1 卡片在 0.125 缩放下控件不可用，是本次改版核心动因）。
- 未指派屏：右侧只有 `[选择壁纸]` 主按钮。

**状态处理**：
- 拔出已指派的显示器 → 小像消失，横幅提示「副显示器已断开，其配置已保留，重新接入自动恢复」；库卡片上该指派角标变灰
- 全屏暂停/电池暂停 → 状态胶囊如实显示（`⏸ 全屏应用中`），与托盘角标一致
- 无显示器：沙盘居中空态（简线图标 + 「未检测到显示器」+ [重新检测]）
