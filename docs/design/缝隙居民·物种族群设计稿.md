> 状态：草案——设计框架与候选清单已成，**首发物种待拍板**。
> 宪法：《[缝隙宇宙·世界观设定集](../archive/design-drafts/drafts/缝隙宇宙·世界观设定集.md)》v1（2026-10-25 起为角色/美术/文案唯一上位依据）。

## 1. 设计顺序（四层，不许跳层）

| 层 | 回答的问题 | 依据（全部出自设定集） |
|---|---|---|
| 世界定律 | 这个宇宙的生命靠什么成立 | 拟态律 / 注视律 / 三创世说 |
| 族群 | 谁跟谁是一伙的，为什么 | 起源说 × 生态位 × 食性 |
| 物种 | 长成屏幕上的什么、住在哪 | 拟态域 × 缝隙地理 |
| 个体 | 剪影 × 配色 × 性格包 | 图鉴变体公式 + 视觉圣经 |

形状归类（团子/动物/物件/幽灵）不是设计输入，是个体剪影层的输出——先归类再设计就是跳层。

## 2. 族群结构：三创世说 = 三族群

| 族群（暂名） | 起源说 | 基调 | 气泡语气 |
|---|---|---|---|
| 老居民 | 浮游说 | 沉静、见过「删除」的时代 | 短、慢、偶尔用旧词 |
| 暖系 | 余温说 | 恋家、温暖 | 软、贴身、多为「你」操心 |
| 新来 | 旅人说 | 闹、好奇、没剧本 | 快、跳、爱玩梗 |

- 族群是身份认同层（Flight Rising flights 的对应物）：v1 不做玩法，只做身世文案与语气差异。
- 图鉴映射表曾提「四群落」：以三说法为准；第四个位置留给**野生居民**（拟态律的 UGC 出口——「外面长成的」，没有可宣称的身世），v2+ 再启用。
- 食性细分（注视律）：每个物种必须写清「它靠什么样的被看见活」——这是行为与动画差异的根。

## 3. 物种候选清单（从律推导，四名）

每个物种 = 拟态来源 + 生态位 + 起源说 + 食性 + 剪影承诺 + 部件池域。名字均为暂名。

### 3.1 暖溪睡客（猫形）——设定集两处钦定

- **拟态**：看猫视频长大的居民（拟态律原文场景）；地理表原文「猫形居民睡在这（暖溪）」。
- **生态位**：暖溪（任务栏余温）；**起源**：余温说（暖系）；**食性**：被看时睡得安稳——云养猫的互文，它也在云养你。
- **剪影承诺**：蜷圆 + 双耳 + 尾，黑剪影一眼可辨（Slime Rancher 剪影法）。
- **部件池域**：毛色（出生第一画面）/ 耳型 / 尾型 / 花纹 / 捡的宝贝（瓶盖纽扣——视觉圣经「组装修饰」条）——真实生活参照最丰富，特征清单公开化（Wobbledogs 式收集）最好做。
- **首发成本：四者最低**——旧猫探索稿的 10 语义动作演出、文案语气、已实机验证的行为状态机（P1/P2 十二项行为断言）全部继承，美术只做「把占位猫换成缝隙猫」的视觉层。
- **风险与反驳**：满桌 IP 猫。但 IP 猫是租来的角色；这一只的合法性来自拟态律——「它看猫视频长成了猫」。差异要靠像素风锁 + 黑剪影 + 缝隙视觉元素（出身说是气泡而非贴图）守得住。

### 3.2 随光（光标居民）——agent 信使的化身

- **拟态**：光标——每块屏幕常驻物中唯一被视线主动追随的。
- **生态位**：桌角镇游荡带；**起源**：旅人说（新来）；**食性**：注视律最优解——你工作时它永远在你视野里被看见。
- **信使传统**（设定集 §5）的天然承担者：离数据流最近，P3 agent 报信的物种化落点；光标 feed 桥（iMouse）已有工程基础。
- **剪影承诺**：箭头/手形变体 + 尾迹；**部件池域**：光标形态（箭头/手/转轮/输入杆）/ 拖拽的宝贝 / 尾迹节律。
- **风险**：动作表达域窄——光标怎么睡、被摸怎么反应全要发明（成本接近拟物物件档）；性格易工具化（Clippy 阴影），反件三律必须写进它的行为稿。
- **定位：第二物种预留**，随 P3 通知能力一起「搬出来」（发布节奏对齐，不需要首发承担）。

### 3.3 逐光居民（光点/萤形）——数据灯平原原住民

- **拟态**：屏幕光点（通知 LED / 加载点 / 萤火虫视频）；地理表原文「数据灯平原……逐光居民在此聚餐」。
- **起源**：浮游说（老居民——「数据的深海浮游」最古老说法的活化石）；**食性**：以数据灯的光为食，兼被人看。
- **剪影承诺**：光点 + 微翅；**部件池域**：光色（第一画面）/ 翅型 / 尾光节律。
- **风险**：太抽象会读成屏保特效，情感锚定全押脸部与节律（概念稿审查中 D 方向同款风险）。
- **定位**：图鉴入册，v2+ 观察首发物种的生命感数据再决定。

### 3.4 桌角团子（像素原生物）——旅人说原文里的「路人身边的团子」

- **拟态**：像素本身 / 背景路人团子（旅人说原文）；**生态位**：桌角镇（设定集 §0「桌角缝隙里住着一群」的最直译）。
- **起源**：三说皆可（通用性最强）；**食性**：陪随时被余光看见（「隔着起雾的玻璃看得清情绪」）。
- **部件池自由度四者最高**（无解剖约束）；剪影 = 圆团 + 附件。
- **风险**：团子是独立游戏默认形态，身份最弱，需要最重的配色纪律与性格文案补偿。
- **定位**：图鉴入册；若首发物种否掉猫形，此为保底选项。

## 4. 三关评估

| 候选 | 剪影可辨 | 部件池友好 | 首发成本 | 资产继承 |
|---|---|---|---|---|
| 暖溪睡客（猫） | ✔ 蜷圆+双耳 | ✔（毛色/耳/尾/花纹/宝贝） | **最低** | 行为状态机 / 10 语义演出 / 文案语气全继承 |

| 逐光居民 | ◐ 光点易混 | ◐ | 高 | 无 |
| 桌角团子 | ◐ 圆易混 | **最高** | 低 | 果冻占位模板部分可参考 |

## 5. 首发推荐

**暖溪睡客（猫形缝隙生物）首发；随光第二预留。**

理由：①世界观两处钦定（拟态律原文 + 地理表原文），合法性不用发明；②三关总分最高，尤其首发成本——行为层已按小动物语义实机验证，美术与文案是增量而非重做；③它正面解决「猫是临时占位」的历史问题：**占位猫死掉，拟态律猫诞生**——同一个形状，第一次有了来处，且与满桌 IP 猫在世界观层面划清界限。

若否猫形：桌角团子保底（部件池最好，身份感靠文案硬拉）。

## 6. 物种包模板（设定集 §7「物种 = 系列」的具体化）

每个物种一份包，字段固定：

1. **出身故事**：三说之一 + 一句族群众生相
2. **一套像素**：画布尺寸 + 色板组（随视觉稿定稿；程序不压缩原则见《小蜡烛·角色设计方向.md》§3 修订条目）
3. **一份性格**：基调 + 气泡语气样本
4. **剪影承诺**：黑剪影测试图（双底：浅/深壁纸，回收自概念稿验收框架）
5. **部件池清单**：槽位 × 变体 × 色板组 → 喂《美术交付契约》
6. **10 语义动作映射**：每动作该物种的演出方向 + 帧结构（B 循环 / ABC / Single）
7. **名字域**：中英语言对候选（定稿时本机查重规则沿用生成规格）
