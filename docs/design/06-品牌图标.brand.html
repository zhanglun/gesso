托盘字形构造

24 网格 · 双层圆角矩形 · 读法：壁纸从前层（桌面）之下探出
  • 留缝前层外扩 1.75 → 16px 下不粘连
  • macOS黑字形 + template · 内嵌 44px@2x（22pt 约束，Retina 清晰）
  • Windows白字形 32px（深色任务栏）· 黑 32px 备浅色
  • 运行时main.rs::tray_icon_rgba

使用规则

改图形先改 DESIGN.md §品牌图形 与源 SVG，再跑管线
  • ✕托盘字形上色 / 加投影 / 带底板 — template 机制要求纯黑+alpha，系统负责亮暗
  • ✕用彩色应用图标缩充当托盘 — 16px 下色浪成噪点，双层矩形才可读
  • ✕旋转 / 重排渐变色相次序 — 蓝始终主导，暖只做收边（地平线在右）
  • ✓≤32px 一律 compact 稿 — 手改 PNG 禁止，一律 tools/build.mjs 产出
  • ✓产出随仓库提交 — 运行时只 include_bytes! 产物，不依赖 node 工具链
产物 crates/app/assets/icons/：mac/Gesso.icns · win/gesso.ico · tray/*.png 再生成：cd crates/app/assets/icons/tools && npm i && node build.mjs Gesso · 跨平台动态壁纸引擎
