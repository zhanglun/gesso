# 宠物世界观 · v1 最小设定

> 状态：**v1 草案**。起源方向与四条世界规则已确认；正式术语和命名待定稿。
> 范围：一页纸，只回答「宠物为什么在桌面上」和支撑产品行为的少量规则。完整宇宙、起源神话、地理、节日和多居民设定不在 v1；相关素材见探索稿《缝隙宇宙·世界观设定集.md》（仅作素材库，不是当前约束）。
> 角色形态已定为拟物小蜡烛（见《小蜡烛·角色设计方向.md》）；视觉细节与名字仍待定。

## 1. 起源（已确认）

屏幕的像素之间存在**缝隙**——一层人类看不见的空间。宠物是住在缝隙里的小生命：它们本来就存在，不是被创造出来的。

Gesso 是画布的底料层，托住整个桌面。打开 Gesso，等于点亮了缝隙通往桌面的灯；宠物循着灯光出来，在桌面上住下。

用户**领养**它：从候选中选中一只，它搬进来。它不需要喂养，也不会因此死亡或离开——被看见、偶尔被摸一下，就是它全部的期待。

## 2. 四条世界规则（已确认）

每条规则直接对应产品行为，世界观不为行为之外的内容服务：

| 规则 | 世界观说法 | 产品行为 |
|---|---|---|
| 不打扰工作 | 它从不进入人类的窗口，只在画框外活动 | 不遮挡工作内容；全屏应用时退回缝隙，退出后回来 |
| 不会死亡消失 | 缝隙里最坏的事是无聊；它不会死，只会睡 | 无死亡、饥饿、离家出走；长时间无人互动就睡着 |
| 感知时间 | 屏幕亮是它的白天，锁屏是它的夜 | 跟随本机节奏作息：空闲入睡、鼠标接近或显示时唤醒 |
| 只属于这台电脑 | 缝隙不出网，记忆只存在这台机器里 | 全部数据本机保存；无账号、无云、无跨设备迁移 |

## 3. 与用户的关系（已确认）

- **领养而非召唤**：用户主动从候选中选择，它固定住下，不会自己跑来。
- **陪伴而非照顾**：用户不承担喂养和打卡义务；摸、戳、看它就足够。
- **共同经历留在本机**：陪伴时间和互动次数是它和用户共同经历的记录，不联网、不同步。

## 4. 术语（候选）

| 用词 | 含义 | 状态 |
|---|---|---|
| 缝隙 | 宠物居住的、屏幕像素之间的空间 | 方向已确认，正式用词待定 |
| 领养 | 用户从候选中选择一只并固定陪伴 | 已确认 |
| 族群称呼 | 「缝隙居民」等仅为候选 | 待角色设计定稿 |

## 5. v1 不解释的（留白）

- 缝隙的最深处有什么。
- 它们是否有同伴、如何交流。
- 多台设备的缝隙是否相通。
- 起源神话（浮游说、余温说、旅人说）——留在探索稿，v1 不采用。
- 地理、节日、图鉴——留给后续版本。

## 6. 界面露出方式

世界观不主动解释：不出现在首次领养流程的强制文案里，不常驻展示。它只通过角色简介、少量气泡和未来的彩蛋低曝光露出；用户不读设定也能完整使用宠物。
