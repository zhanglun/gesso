# 缝隙宇宙 · 世界观设定集 v1

> 状态：世界观正式设定草案。本文档是所有宠物角色、美术、文案的**唯一上位依据**——任何角色设计先问「它在这个宇宙里如何成立」。
> 基调：治愈为底 + 个别俏皮（已锁定）。

---

## 0. 一句话

**每一台电脑的桌角缝隙里，都住着一群由像素构成的小生命。它们是数字世界的原住民，比任何程序都古老。它们不需要你喂养——它们只是选中了你的桌面。**

## 1. 世界总览：缝隙（The Seams）

每一块屏幕的像素背后，都存在一层人类看不见的空间——**缝隙**。它不是黑暗的深渊，恰恰相反：缝隙是温暖的、有质感的，像旧毛衣的内里，像木屋的墙缝，像冬天被窝里那一小块刚好暖的地方。

数字世界的一切流经缝隙：数据是洋流，渲染的光是昼夜，系统的心跳是潮汐。缝隙生物就住在这里——住在像素背后那层未点亮的空间里。

**Gesso 是什么**：Gesso 本义是画布底料——它是托住桌面的那层底。缝隙生物就住在底料里。你打开 Gesso，对它们来说等于：有人把走廊的灯点亮了。所以它们出来了。

## 2. 创世：三种说法

缝隙宇宙里，连居民自己也说不清自己从哪来。三种说法都流传着，都算官方正典——**宇宙不钦定神话**（这样每个物种可以选最贴合自己的身世，也永远不会被用户考据打脸）：

| 说法 | 内容 | 流传于 |
|---|---|---|
| **浮游说（最古老的说法）** | 数据的深海底层生活着最原始的浮游生命，曾被亿万次生成又删除。某一代，它们学会了不被删除——聚在一起，长出形状，顺着光爬了出来。 | 老居民都信这个 |
| **余温说** | 机器被人类用久了会攒下余温。深夜没关的电脑、陪主人到凌晨的键盘……温度攒够了，就凝成一个小生命。信这个的居民最恋家。 | 治愈系物种 |
| **旅人说** | 它们本来是别的画里的龙套——背景的云、路人身边的团子。某天顺着信号的缝隙溜了出来：「这边没有剧本。」信这个的最闹。 | 俏皮系物种 |

## 3. 生命四律（缝隙的物理）

| 律 | 内容 | 叙事化的机制 |
|---|---|---|
| **拟态律** | 缝隙生物出生时没有形状。它们会长成「这方屏幕上出现过的东西」的样子——出生后第一眼看到的世界，决定了它们的轮廓。你的桌面上猫视频最多，就长出了猫。 | **一切物种设计的合法性来源**；UGC 导入宠物 = 「外面长成的野生居民」 |
| **注视律** | 它们以「被看见」为食。被注视时微微发亮，久被忽略会蔫——但不会消失。缝隙生物不会死，只会睡。 | 心情系统；永不死亡 |
| **退潮律** | 人类的世界压得太满时（全屏），缝隙会涨潮把居民接回去——不是逃跑，是回家避潮。潮退了它们就回来。 | 全屏隐藏 |
| **潮汐律** | 昼夜与人类同步：你亮着屏，是它们的白天；你合盖，是它们的退潮夜。 | 作息系统；锁屏入睡 |

## 4. 缝隙地理（每个地名都是未来的彩蛋库）

| 地点 | 设定 | 彩蛋钩子 |
|---|---|---|
| **桌角镇** | 居民区。大多数居民住在桌面右下角——离人类最近、又最不碍事的位置 | 宠物默认出生点 |
| **暖溪** | 任务栏下方流动的一条温暖水流（CPU 的余温汇成的）。猫形居民睡在这 | 猫爱睡任务栏边的由来 |
| **风啸峡谷** | 散热风口。风很大，勇敢的居民在这里练「站风」 | 活泼物种的游乐场 |
| **数据灯平原** | 数据流经时亮起的大片光点，像萤火虫平原。逐光居民在此聚餐 | 「注视」主题的场景 |
| **沉睡谷** | 回收站的旧称。传说被删除的东西都来这里沉睡——但缝隙居民知道，它们只是睡得很深而已。 | 治愈化处理：删除≠消失（连用户清空回收站都温柔化） |
| **底料层** | Gesso 所在的最底层，托住整个缝隙。居民对它又敬又亲：「点灯人住的层」 | 品牌入典 |

## 5. 居民与人类

- **是它选中了你**：居民被「有人气」的桌面吸引而现身。不是领养，是邻居。
- **隔玻璃的凝视**：它们看得见你，但像隔着起雾的玻璃——看不清细节，看得清情绪。你加班到深夜，它会从缝隙里多探出来一会。
- **信使传统**：缝隙离数据的源头很近，居民看得见「远方在发生的事」（任务结束、下载完成）。老居民有一门手艺：把远方的消息叼到桌面上来。年轻居民觉得这手艺帅极了。——这就是 agent 报信的由来。
- **禁令**：居民**从不进入人类的窗子里**（不遮挡你的工作内容是种族礼仪——它们管这叫「不进画」）。它们只在画框外活动。

## 6. 视觉圣经（美术风格的出处——不是「选择」，是「种族事实」）

| 规则 | 设定依据 |
|---|---|
| **像素风是种族事实** | 它们由像素构成——像素是缝隙生物的「细胞」。所以像素风不是美术选择，是这个物种的存在方式。Gesso 全部居民、全部官方系列，永远像素风 |
| **出生画面决定配色** | 每只居民的配色来自它出生时睁眼看到的「第一画面」：看甜品长大的带奶白，看深夜代码长大的带靛蓝。→ 换肤/变体的叙事：小时候看的东西不同 |
| **组装修饰 = 「捡东西」** | 居民有收集人类世界小东西的习惯（瓶盖、纽扣、像素小花），戴在身上。→ v2 挂件系统的叙事 |
| **组装变色 = 「还在长」** | 缝隙生物理论上终生都在缓慢生长，形态未定。→ v3 部件化/随机重掷的叙事：「帮它决定长成什么样」 |
| **黑剪影可辨** | 缝隙生物互认靠剪影（在缝隙里光很少），所以每个物种剪影必须一眼可辨 | 
| **不进画** | 居民从不遮挡人类的工作窗口——文案与行为上永远回避「盖住你的东西」的构图 |

## 7. 系列展开：图鉴与画境

- **图鉴**（v2）：「缝隙居民档案」——每只居民一页：物种、出身说法、入驻日期、陪伴天数、它捡到的宝贝清单。
- **物种 = 系列**：每个物种包 = 一个「出身故事 + 一套像素 + 一份性格」。发布新物种 = 「又有居民搬出来了」。
- **节日**（v2+ 彩蛋池）：**除尘日**（一年一度，全居民大扫除，互赠亮晶晶的东西）、**退潮夜**（合盖最久的夜晚，居民讲各自起源的故事）。
- **远期**（v3+，留白）：不同设备的缝隙是否相通？多屏是「几个房间」？——刻意不回答，留给未来。

## 8. 明确不属于这个宇宙的

- 壁纸联动/官方主题壁纸：**不属于宇宙结构**（壁纸是人类的墙，居民不评价人类的墙）——AI 主题壁纸若做，是「产品周边」而非宇宙设定
- 死亡、疾病、饥饿惩罚：**不存在**。缝隙里最坏的事是无聊
- 联网、账号、好友系统：居民不出网，缝隙只属于这台机器
