## 0. 世界观头部（两句话）

它们是**缝隙居民**——从电脑桌角的缝隙里搬出来的数字小生命，长成你屏幕上出现过的东西的样子。是它们选中了你，不是你领养了它。

- 猫：最早醒来的那批居民，长成了人类最古老伙伴的样子。
- 麻薯：从点心包装的缝隙里滚出来的一只，Q弹是它的天赋，也是它的生活方式。

## 2. 角色卡 A：猫（默认安静档）

| 项 | 内容 |
|---|---|
| id | `gesso.cat`（名字定稿后更新，如 `gesso.mimi`） |
| 名字候选 | **眯眯**（en: Dozy，爱眯眼）/ **灰灰**（en: Smudge，灰蓝色毛）/ 屏屏（en: Screeny，梗味）——**待用户三选一或另起** |
| 一句话人设 | 缝隙里最早醒来的居民，长成了人类最古老伙伴的样子。一天睡十六个小时，醒来 mainly 为了换个地方睡——但只要你伸手，它就会过来。 |
| 性格关键词 | 慵懒治愈、嘴上淡定身体诚实、呼噜藏不住 |
| 外形概念 | 圆润矮身猫，蓝灰色毛，淡粉内耳，半眯的慢悠悠眼睛，尾巴常摇 |
| 默认打扰档 | `quiet` |
| walk 速度 | `move: 14`（散步步速） |

| 反 boring 转译 | P3：agent 工作时耳朵竖起、尾巴打直（RunCat 式）；爱睡「暖处」= 屏幕底缘任务栏边 |

## 3. 角色卡 B：麻薯（默认活泼档，Q弹人设）

| 项 | 内容 |
|---|---|
| id / display | `gesso.mochi` · 麻薯（en: Mochi） |
| 一句话人设 | 从点心包装的缝隙里滚出来的一只。全身都是弹的：走路是弹的，开心是弹的，连打盹都在微微弹。坚信桌面上的一切都可以弹一下试试。 |
| 性格关键词 | Q弹、好奇、自来熟、用弹跳表达一切情绪 |
| 外形概念 | 圆润方团子，奶白色主体，淡粉腮红，两粒黑芝麻眼睛，小短手——移动方式是「弹」而非走 |
| 默认打扰档 | `lively` |
| walk 速度 | `move: 26`（弹跳步，每步带 2px 起伏） |
| idle 节奏 | 眨眼中等（~5s），身体轻微 Q 弹呼吸感 |
| 动作冷却系数 | ×0.8 |
| 俏皮位 | 活泼档 + 弹跳恶搞（把一切理解成「能不能弹」），承担「个别俏皮」 |

**AI 风格稿 prompt（待试产）**：

```text

per color, crisp edges, no anti-aliasing, soft limited palette (max 4 colors).
Character: a soft white mochi dumpling creature, rounded-square body, pale pink blush
cheeks, two tiny black sesame eyes, stubby arms, bouncy jelly-like energy, joyful vibe
```
