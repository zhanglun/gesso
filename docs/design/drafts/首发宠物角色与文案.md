## 0. 世界观（一句）

**它们是画布世界的居民**——Gesso 本义是画布底料，壁纸是画布，这两只是从画材里溜出来、住进你桌面的原住民。所有文案不用「主人/玩家」称呼，宠物视角里你就是「同桌的人」。

## 1. 角色卡 A：麻薯 / Mochi（默认安静档）

| 项 | 内容 |
|---|---|
| id / display | `gesso.mochi` · 麻薯（en: Mochi） |
| 一句话人设 | 一盘白玉麻薯里最小最软的那只，从甜点店窗台逃进了桌面。一天睡十六小时，剩下八小时在准备睡。 |
| 性格关键词 | 软、慢半拍、无-pressure 治愈、被扔了也不生气（年糕心态） |
| 外形概念 | 圆润方团子，奶白色主体，淡粉腮红，两粒黑芝麻眼睛，小短手短腿——走路整体挪动，几乎看不出腿 |
| 默认打扰档 | `quiet`（很少挪窝、几乎不冒泡） |
| walk 速度 | `move: 12`（慢挪） |
| idle 节奏 | 眨眼间隔长（~8s），伸懒腰幅度小 |
| 动作冷却系数 | ×1.5（比默认更不爱上动作） |

**AI 风格稿 prompt（英文，供图像工具试产）**：

```text
pixel art sprite sheet, modern clean pixel style, 192x208 per cell, 8-column grid,
side-view chibi mascot, transparent background, 2-3 shades per color, crisp edges,
no anti-aliasing, soft limited palette
character: a soft white mochi dumpling creature, rounded-square body, pale pink
blush cheeks, two tiny black sesame eyes, stubby arms and legs, gentle sleepy vibe,
slight squash-and-stretch
```

## 5. 动作帧参考（给 AI 出帧的逐动作提示，14 动作）

| 动作 | 帧数 | 关键帧提示 |
|---|---|---|
| idle | 4（循环） | 站立 → 眨眼 → 站立 → 微张望 |
| walk | 6 | 起步/挪×4/并步（墨墨每帧带 1px 上跳） |
| poked | 4 | 压扁 → 弹起 → 回位 |
| petted_happy | 6 | 闭眼眯 → ♥ 上浮 → 再眯 → 收 |
| petted_head | 6 | 低头受摸 → 眯眼 → 腮红加深 |
| poked_belly | 4 | 肚子凹陷 → 弹回 → 双手护肚 → 瞪 |
| grabbed | 4 | 离地 → 悬空晃腿 ×2 |
| thrown_spin | 4 | 空中翻滚 ×2 姿态交替 |
| land_bounce | 4 | 压扁 → 半弹 → 全弹 → 回位 |
| get_up_glare | 4 | 爬起 → 抖尘 → 转头瞪 |
| sleep_lying | 4（循环） | 趴下 → 闭眼 → ZZZ 浮动 ×2 |
| wake_stretch | 4 | 伸懒腰 → 打哈欠 → 揉眼 → 回 idle |
| hide | 4 | 环顾 → 溜边 → 淡出 |
| wave | 4 | 举手 → 摆 ×2 → 收 |

> 出帧顺序建议：先出 idle + walk 两动作试风格一致性（同一角色 14 动作不变形是 AI 产线最大风险，见设计文档 §10），通过后再批量。
