## 1. 核心设定（一段话版本）

> 每一台电脑的桌角缝隙里，都住着一群古老的数字小生物。以前没人见过它们——旧桌面太暗、太乱。现在的桌面亮了、空了、也寂寞了，它们被「人气」吸引，陆续搬了出来。它们没有固定长相：**缝隙生物会慢慢长成「这方屏幕上出现过的东西」的轮廓**——有人常年看甜品视频，缝隙里就长出了年糕团子；有人天天写稿，就渗出一滴墨。是它们选中了你，不是你领养了它。

## 2. 四个设定杠杆

| 杠杆 | 解释 | 兑现了什么 |
|---|---|---|
| **长成你屏幕上出现过的东西** | 物种形态模仿用户世界的痕迹 | 一句话解释一切物种（官方系列 + UGC 导入全部天然成立） |
| **是它选中了你** | 反转领养叙事 | 轻养成无惩罚的世界观化：不喂不走，最多蔫 |
| **Gesso = 底料层** | 软件本义（画布底料）即它们居住的那一层 | 品牌零成本入典，不造新词 |
| **壁纸 = 墙上的画** | 完全解耦：换壁纸它们顶多瞟一眼 | 壁纸自由属于用户；AI 宠物主题壁纸列为 v2+ **可选彩蛋**（如「它眼里的家」），不承担叙事结构 |

## 3. 存在法则（已有机制 → 叙事映射，零新代码）

| 机制 | 叙事 |
|---|---|
| 心情系统（互动为食） | 它们以「被看见」为食 |
| 全屏躲藏 | 大东西路过，让一让 |
| 夜晚/空闲入睡 | 缝隙的作息跟着人走 |
| agent 报信（P3） | 它们看得见机器里流动的事，愿意替你跑腿 |
| 久坐提醒（P2） | 它们自己也想躺，顺口劝你 |
| 陪伴天数（存档 metrics） | 它在桌角住了 N 天 |

## 4. 系列与生态结构

- **物种 = 系列**：每个物种一个精灵包（manifest + 素材 + 文案 + 性格参数），按「画材/日常物」主题成谱系：年糕团子、墨滴、小陶偶（怕摔、慢吞吞）、线团球（爱缠鼠标线）、棱镜雀（跟随系统主题色变色）、信号精灵（最「数字」的一只，天然承接信使角色）……谱系可无限延伸，每个新物种 = 一次发布节奏。
- **正典与旅人**：官方物种 = 正典；用户导入的宠物 = 「野生的 / 别家搬来的」——图鉴一视同仁，格式完全通用（manifest 不分贵贱）。宇宙不当守门人。
- **收集层（v2）**：管理窗口宠物页 = **图鉴**——每只一张档案卡（物种、来源、入驻日期、陪伴天数、彩蛋记录）。数据源 = 设计文档 §7 已预留的 milestones 字段，零新基建。

## 5. 待用户定调

1. **味道**：治愈系（默认草案基调：软、慢、暖）／俏皮系（更多恶搞与捣乱）／神秘系（缝隙的来历留白更多）。可混合（建议：治愈为底、个别物种俏皮）。
2. **命名**：宇宙名候选——「**缝隙**」（The Seams，草案默认）/「桌角」（Cornerfolk）/「洞居」（Hollows）。两角色与宇宙名的命名体系要协调。
3. **首批物种清单**：麻薯（年糕团子）/ 墨墨（墨滴）是否保留为前两只（当前候选），还是从新谱系重选。
