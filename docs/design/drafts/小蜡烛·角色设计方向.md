# 桌面宠物角色设计方向 · 小蜡烛

> 状态：**方向已确认，视觉稿待做**。工作名「小蜡烛」；正式名字、色值和帧表待视觉基准图定稿。
> 依据：《桌面宠物产品与视觉方向决策稿.md》《宠物世界观·v1最小设定.md》。
> 修订：形态曾探索「抽象光团（光团萤火）」，后按「从现实生物/物件衍生」的要求收敛为拟物小蜡烛；火苗保留了暖光灵魂。

## 1. 一句话

从屏幕缝隙里探出来的一小截奶油色蜡烛，火苗是它的生命状态——亮是清醒，暗是睡着，但它永远不会烧完。

## 2. 已确认的设计决策

| 维度 | 结论 |
|---|---|
| 形态 | 拟物小蜡烛：奶油色蜡身 + 顶部暖橙火苗，点眼在蜡身正面 |
| 性格 | 安静观察者：发呆、观察、睡觉，有反应但不讨好 |
| 配色 | 暖色奶感：奶油/奶白蜡身 + 暖橙火苗；具体色值待视觉稿 |
| 表情 | 点状眼 + 偶尔眨眼；嘴部有无待视觉稿 |
| 物种 | 无物种：蜡烛是物件不是生物，不与「不绑定现实物种」冲突 |
| 存在感 | 小而克制，桌面上不抢注意力 |

**物种设计公式**：未来新物种沿用同一方法——优先从现实生物/物件衍生拟物化（候选方向：蘑菇、茶宠、蜗牛、不倒翁、萤火虫等），每个物种自带独立部件池，架构详见《宠物个体生成规格.md》「角色层与个体层」一节。

## 3. 形态细节方向

- **蜡身**：矮圆柱，下缘微宽坐得稳，轮廓圆润；正面点眼。
- **火苗**：生命状态指示器——大小、亮度、摇曳幅度表达清醒度；火苗本身不画表情。
- **设计红线：永不烧短**。蜡身长度恒定，火苗只表达状态、不表达寿命；杜绝「燃尽=死亡」隐喻。蜡烛也不会随时间"变矮"或"流泪变少"。
- 可选手作感细节（待视觉稿）：侧面一两道凝固蜡泪痕、底部浅托盘。
- 无手无脚；移动=底部小碎步蹭行，火苗随步伐轻晃。

## 4. 动作语义映射（10 语义 × 蜡烛表现）

| 语义 | 表现方向 |
|---|---|
| `idle` | 火苗轻轻摇曳（幅度很小），偶尔眨眼 |
| `watch` | 眼睛随光标移动，火苗微微倾向光标方向 |
| `walk` | 小碎步蹭行，火苗随步伐晃动 |
| `sleep` | 火苗变暗变矮几乎熄灭，只剩一粒豆大的微光，眼睛闭合 |
| `wake` | 火苗重新立起变亮，眼睛睁开 |
| `poked` | 火苗猛地窜高一下随即回落，眼睛圆睁 |
| `petted` | 火苗变暖变亮 + 眯眼 |
| `notify_result` / `notify_attention` | 火苗轻跳 + 气泡 |
| `notify_warning` | 火苗明显蹿高偏橙红一瞬 + 气泡 |
| `hide` | 像被缝隙收回去一样，火苗先熄、蜡身渐隐 |

reduced-motion 静态替代：摇曳/晃动/渐变全部停用，用火苗大小档位（清醒大/睡眠小）和眼睛开闭表达状态。

## 5. 工程含义

- 占位层升级路径：现有圆角矩形蜡身保留；顶部新增火苗图层（预渲染位图帧或径向渐变 + 摇曳动画）+ 顶部微光晕；眼睛/眨眼逻辑复用现有 gaze 图层。
- Sleeping 的整窗 opacity 0.72 表现改为「火苗变小变暗」为主的语义正确表达。
- 命中区域继续用身体矩形（蜡身），火苗与光晕不参与命中。
- 通知气泡继续用头顶占位气泡；注意气泡与火苗的垂直空间分配（窗口 headroom 已预留）。
- 摇曳动画用 CAAnimation 循环（低幅度）；reduced-motion 下切静态火苗帧。

## 6. 与世界观衔接

- v1 最小设定：「打开 Gesso，等于点亮了缝隙通往桌面的灯」——小蜡烛就是被点亮后留在桌面上的那盏小灯。
- 「屏幕亮是它的白天」：火苗与屏幕作息同呼吸；锁屏夜=火苗昏暗。
- 「它不会死，只会睡」：蜡烛不烧短是同一句话的形态化——光永远在，只是暗下去。
- 「不打扰工作」：一截小蜡烛的亮度克制，天然不吸睛。
