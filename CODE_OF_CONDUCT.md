# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in everything we do here — issues, PRs, reviews, chat.

The short version: be professional and kind, critique code rather than people, and assume good faith. Harassment of any kind is not tolerated.

Report issues to the repository maintainers via GitHub. Enforcement is at maintainers' discretion and may result in removal from project spaces.

中文社区同样适用本准则。
